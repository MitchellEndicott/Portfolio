Smart Track

A C++ program that builds a weekly training plan for track and field athletes from their events, goals, personal records and schedule.

Type
Individual class project (CS1 final project)
Language
C++
Input
Up to 4 of 17 events, up to 2 training goals, track and gym PRs, weekly availability windows
Output
A weekly plan of track workouts and gym sessions, with lift loads scaled from the athlete's PRs
Features
Input validation, no repeated drills in a row, and a weekly check-in that reschedules a missed workout
Code
github.com/MitchellEndicott/Smart-Track
How it works

Input

  1. Athlete events
  2. Training goals
  3. PRs
  4. Weekly availability

Process

  1. Validate inputs
  2. Select workouts
  3. Scale lifting loads
  4. Schedule workouts
  5. Handle missed sessions

Output

  1. Customized 7-day training plan
